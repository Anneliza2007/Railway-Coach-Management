# 🚂 Railway Coach Management using Deque

## Overview
This project is a menu-driven C program that simulates a Railway Coach Management System using a Double Ended Queue (Deque). The program allows coaches to be added and removed from both the front and rear of the train.

## Features
- Insert coach at the front
- Insert coach at the rear
- Delete coach from the front
- Delete coach from the rear
- Display all coaches
- Handles overflow and underflow conditions

## Data Structure
- Double Ended Queue (Deque)
- Array implementation

## Language
- C

## Concepts Used
- Arrays
- Functions
- Circular Deque
- Menu-driven programming

## Sample Menu

1. Insert Front
2. Insert Rear
3. Delete Front
4. Delete Rear
5. Display
6. Exit
